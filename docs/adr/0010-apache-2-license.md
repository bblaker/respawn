# 10. Apache-2.0 license

- **Status:** Accepted
- **Date:** 2026-10-26

## Context

The project needs an open source license before publishing code.

## Decision

License respawn under the Apache License 2.0.

## Consequences

- The Kubernetes ecosystem norm, which makes reuse and contribution unsurprising.
- Includes an explicit patent grant.
- Contributions are accepted under the same license, with DCO sign-off.
